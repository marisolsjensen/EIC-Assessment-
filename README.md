EIC Accelerator Eligibility Assessment

Overview

The EIC Accelerator Eligibility Assessment is a web-based tool designed to help startups, SMEs, and mid-caps evaluate their suitability for the EIC Accelerator funding program. By answering a short series of questions, users receive instant feedback on their eligibility and recommendations for next steps.

Features

✅ Interactive questionnaire with key eligibility criteria.

✅ Instant feedback based on EIC Accelerator requirements.

✅ User-friendly interface for quick assessment.

Installation & Running Locally

To run this project locally:

Prerequisites

Ensure you have Node.js and npm installed. You can check this by running:

node -v
npm -v

If not installed, download Node.js from here.

Steps

Clone the repository:

git clone https://github.com/YOUR_USERNAME/eic-assessment.git

Navigate into the project folder:

cd eic-assessment

Install dependencies:

npm install

Run the development server:

npm run dev

Open http://localhost:3000 in your browser.
